# Solid Market Researcher

Solid Market Researcher 为使用 AI agent 开展市场研究和撰写客户营销提案的研究人员、分析师提供可复用技能。三个技能覆盖结论先行的写作、研究与交付审查，以及视觉表达的选择和成品检查。

配套 Python 工具将来源、证据和适用范围与引用用途、结论、报告及图表位置、APA 参考文献串联起来，导出 TTL 证据图谱，并提示记录缺失、失效或不一致。分析师需阅读原始来源，判断证据能否支持当前报告的结论。对外发布须获得明确授权，并回读核验实际内容。

## 从哪里开始

在 [AGENTS.md](../AGENTS.md) 查看研究流程，按当前阶段读取写作、审查或制图 Skill。研究开始前，先确定这份分析要支持什么决策、覆盖哪些对象和市场、采用什么时期的数据。用户意图缺失且会改变路线时分轮追问，公开事实由 agent 查找。

原文审查从已取得的来源正文开始：先读定义、方法、数据及脚注，独立记录地区、总体、分母、时期和指标，再与当前报告原句比较。来源、解释或报告句子变化后，相关审查需要重新核对。脚本负责检查锚点、连接和版本绑定；分析师判断证据是否足以支撑结论。

在 [主 README](../README.md) 查看 Python 环境、命令和合成测试的运行方法。新研究项目在独立私有目录中使用 [状态模板](../skills/review-market-analysis/references/project-state.md) 建立入口。本仓库只保留通用方法、空白模板、工具及虚构测试数据。
