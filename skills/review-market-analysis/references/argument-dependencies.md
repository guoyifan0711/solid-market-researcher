# 跨页依赖表

首轮骨架形成后，以及来源、结论、地区／人群选择、产品角色或分级定义变化时使用。记录会影响后文决策的关系；每页仍只回答自己的主要问题，全篇共同完成论证。

沿用现有骨架、Claim映射或审查记录。已启用 [证据关系图谱](evidence-graph.md) 时，用 Use 连接上游 Claim 与下游 Claim，并登记实际采用位置；本表补充商业上“后续必须回答什么”，不重复维护节点或原文摘录。小修改可直接列出受影响位置。版本、确认与发布状态仍由当前交付清单维护。

## 1. 判断如何传到后文

| 依赖ID | 上游判断／定义及依据位置 | 后续必须回答的问题 | 实际采用位置 | 成立条件／反证 | 本轮处理与核验依据 |
|---|---|---|---|---|---|
| 复用Claim或自定短ID | 指向事实、推断或已确定的选择 | 该输入改变哪项后续决策 | P／表／图／摘要等 | 证据范围、差异或缺口 | 沿用／修改／移除及对应记录 |

可从以下关系检查遗漏，按本项目实际论证取用：

- 前文提出技术、渠道或服务将改变采用条件，地区部分说明当地是否存在这些条件、涉及哪些需求及限制。
- 地区与产品适配判断交给客群和策略页，说明谁优先购买、比较什么、需要看到什么证明，再选择内容、渠道、时机及指标。
- 相同人群标签下，地区的场地、购买习惯、竞品或服务条件不同，后文保留相应差异；合并地区应说明共同的决定因素。

只有一个环节有证据时，将后续保留为有依据的建议、收窄或移除。关键数值若改变排序，应在客户可见的结论或图中呈现，不能只留在底稿。

## 2. 定义与分级的唯一维护位置

对会反复出现的定义指定唯一位置，可使用项目规则、既有术语表或分析表，不要求增加新文件。

| 定义／判断对象 | 唯一维护位置 | 使用位置 |
|---|---|---|
| 指标分母、购买状态、优先级判据等 | 项目内选定的一处位置 | 正文、原生表、图、摘要、Notes／附录、外部稿 |
| 具体地区×人群×产品的级别或选择 | 当前交付清单所指的判定页／分析表 | 下游策略及各交付形态 |

定义与具体组合的判定分别维护。更新后沿使用位置检查，优先由同一份结构化内容生成重复表述；人工维护时逐处核对。允许等义短写，判据、对象及适用范围须一致。历史快照保留原版本，不能回流覆盖当前决定。

## 3. 按本次改动选择复核范围

| 改动 | 必须复核的内容 |
|---|---|
| 纯措辞／语序，事实及判断保持 | 完整句段是否自然，限定与比较强度是否保留；相同用语所在图、表及摘要。新加入的事实另走来源审计 |
| 来源、原值、分母、公式或假设 | 来源适用性、输入／公式／输出，以及所有使用该结果的正文、比较、图、摘要和引用 |
| 核心结论、地区／人群选择、产品角色或分级 | 上游依据及本表列出的下游决策；同时核对定义、具体判定、Notes和术语附录 |
| 页职责／页序 | Part边界、标题、页码、跨页引用、目录和摘要 |
| 图表数据、标签或版式 | 数据映射、限定、正文关联、实际尺寸显示与最终容器；图中新判断进入来源／推导审计 |
| 外部同步 | 本次授权、候选与实际目标的一致性及真实显示；全文替换应回读全文 |

未变部分可沿用与内容版本／哈希绑定的有效审计。不得因“只改文案”漏查实际发生的结论变化，也不因一次词语调整重新研究所有历史来源。

## 4. 提交条件

本轮关键输入的后续用途已明确，受影响位置已处理；删除上游依据时，依赖它的判断已补证、收窄或移除。Review结果沿 Skill 的三个状态记录，技术检查、商业推导和实际展示写清覆盖范围；用户确认、外部授权与回读继续分别登记。未完成项保留具体影响，不以文件存在或登记项检查通过代替语义审查。
