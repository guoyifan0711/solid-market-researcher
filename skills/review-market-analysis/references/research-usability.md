# 研究启动项、追问与指标可用性

新项目启动、目标或范围变化时先读第1节；首次测算、采用新指标或研究边界变化时再读第2、3节。启动信息写入既有骨架或研究任务卡，证据取舍沿用来源登记与 Source ID／Claim ID。

## 1. 研究启动项与必要追问

### 信息基础

每个新项目都按适用性核对下列信息；独立行业研究可无指定客户或 SKU。已有 brief、对话或项目记录能回答的直接引用。用户主要提供业务意图、内部事实及取舍，agent 负责资料查找和研究设计。

| 启动项 | 需要明确什么 | 缺少时如何补齐 |
|---|---|---|
| 决策目的与成功标准 | 这份分析帮助谁决定什么；最重要的问题；什么结果算回答了问题 | 向用户问清要支持的决策。将“了解行业／寻找机会”细化为市场进入、地区排序、产品机会或营销选择等具体问题 |
| 客户、读者与业务背景 | 服务哪个品牌／业务；目前处于何阶段；读者已有认知和需要的判断 | 先读既有材料；会改变分析重点的内部背景向用户补问，公开背景自行核实 |
| 产品、用途与人群 | 纳入哪些品类／产品系列、使用场景及消费者／企业等对象；明确排除范围 | 公开产品信息自行查；本次计划覆盖哪些产品和用途，由用户决定或明确授权 agent 拟定 |
| 市场范围与比较层级 | 国家／地区集合、客户区域分组；按国家、地区还是城市比较 | 向用户确认边界。市场筛选本身若是研究任务，明确候选范围与筛选目的即可，优先市场由研究得出 |
| 研究时期与交付时间 | 分析哪年的现状、支持哪一年的计划／哪段决策期；历史基线和预测窗口；资料截止日与交付期限 | 研究时期不清时追问；agent 依目标提出检索截止日和数据覆盖建议，将数据期与发布日期分开 |
| 成果形式与研究深度 | 提案中的市场部分、独立报告还是专项研究；须交付哪些判断、比较及细分层级；格式或篇幅要求 | 先沿用户现有要求；会改变工作量或分析路线的选项向用户问清，普通版式由 agent 建议 |
| 现有材料与数据入口 | brief、产品资料、既有研究、历史提案、内部经营数据及可访问位置 | 先检索已给入口；确需未提供的内部资料时说明用途和缺失影响。市场规模、份额及公开报告由 agent 研究 |
| 关键约束与取舍 | 必须覆盖／排除的事项、已有业务决定、预算或资源边界、保密及外部操作要求 | 只追问会影响本次研究或执行的约束；外部写入按实际授权办理 |

进入测算前，agent 在同一任务卡补记指标、单位、分母及样本总体，区分收入、销量、出货和存量；涉及优先级／T级时，明确它衡量适配、增量、竞争还是回报。数据方法由研究核实，业务取舍有歧义时再向用户提问。

### 按问题依赖分轮提问

参考 grilling 的问题依赖树和分轮方式：一个已明确的选择决定下一轮该问什么。本节给出可直接执行的方法。

1. **先恢复信息。** 读取适用规则、用户 brief、被引用对话及既有确认记录，区分已知事实、用户决定、可查事实和仍缺的取舍；读取被引用对话后才采用其中内容。
2. **识别必须问的决定。** 先按用户最新明确指令更新边界。目的、对象、用途、市场或研究时期仍缺失、仍有冲突，或有两种会导致不同研究路线的合理解释时，必须向用户提问。事实查找由 agent 完成；只有用户掌握的内部事实可请求补充。
3. **先问上游问题。** 目的尚未明确时先问“支持什么决策”；目的明确后再问依赖它的范围、比较层级和深度。同轮问题的前提必须已明确，彼此没有尚待回答的依赖。
4. **每轮保持简短。** 通常合并1至3个可独立回答的关键问题，说明答案会改变什么，并给出简短选项。有足够上下文时写明建议答案及理由，让用户可直接同意或修正；依据不足时先用开放问题确定方向。用户不确定研究范围时，提出可行方向及各自能回答的问题，帮助其作出选择。使用当前环境的提问工具；无专用工具时直接向用户提问并等待。
5. **收到回答再展开下一层。** 按答案更新研究边界，再问新出现的必要问题。需要用户决定的事项，在回答前不开展依赖它的研究；其间可整理资料、核实公开事实和推进独立工作。未回复或经过一段时间都不表示同意。用户已授权 agent 决定的事项，按授权范围选择并记录依据。
6. **记录启动约定。** 将明确的决策问题、纳入／排除范围、研究时期、交付要求及依据入口写在既有骨架或任务卡。剩余缺口沿当前交付清单登记；已有回复已明确的内容直接作为依据。

例如，用户已说明要为某品牌制定下一年的营销计划，但未确定研究重点，可先问：“这次主要要选择重点市场，还是在已选市场确定人群与内容策略？建议先选择重点市场，这会决定后续人群与渠道研究在哪些地区展开。是否按这个目标开展？”用户选择市场筛选后，再明确候选国家及比较层级；已给出的国家范围直接沿用。

### 开始研究的条件

决策目的、研究对象与用途、市场范围或筛选边界、研究时期足够明确，能据此写出研究问题时，即可开始定向研究。会改变路线的缺口先提问；明确授权 agent 拟定的范围可先形成有依据的方案。交付深度或期限的歧义若会改变研究安排，也须先问清。

公开数据缺失进入第3节的证据处理流程；内部数据不全时说明能回答到哪一层。一般版式和可随研究调整的细节可按现有规范处理。启动约定和建议研究框架在首次定向研究前简短告知用户；意图已明确的授权任务直接推进。

## 2. 关键指标可用性表

每行对应“一个用途下的一项指标／来源”，同一来源可对不同用途得出不同取舍。来源元数据沿原登记，只在此记录适配判断。

已启用 [证据关系图谱](evidence-graph.md) 时，用 Source／Evidence／Scope／Use ID 连接本表与引用关系；适配判断作为 `scope_review.basis` 的依据入口。原文摘录和完整口径只在 Evidence／Scope 维护一次。

| 目标判断／用途 | Source／Claim ID及原文位置 | 口径或证据缺口 | 取舍与允许用途 | 影响的页面／依赖 |
|---|---|---|---|---|
| 按本次问题填写 | 链接既有登记 | 具体说明差异或缺项 | 直接采用／限定使用／排除本用途，并写明原因 | 指向页面或依赖记录 |

### 判定条件

- **规模、增速和绝对增量：**基数、CAGR起算口径、预测窗口、地区、用途、计量及价格口径匹配，未覆盖年份不直接套用。把机构多年度CAGR用于年度推演时，注明“基于机构CAGR的年度推演”及恒定增长假设；未经核实的百分比不作模型输入。可复算路径为 `V_t = V_base × (1+g)^(t-base)`、`年度增量 = V_t − V_(t−1)`，具体公式与来源仍登记在底稿。
- **需求池与采用空间：**家庭、场地或用户存量，以及未采用比例，可支持潜在需求判断；年度购买量还需要更新、转入或购买率等证据。品类增长来源与品牌获客来源分开分析，换机与品牌转移可能重叠，不能直接相加。
- **份额与竞争位置：**品牌与品类的国家、年份、用途、渠道及收入／数量分母匹配。单一渠道份额、上架SKU占比和网站访问量按原定义使用。
- **代理指标与评分：**说明实际测量对象、与目标问题的关联机制、样本代表性及跨地区可比性。用于数值评分时，再记录评分规则、阈值／权重依据、缺失值处理和敏感性；分析评分保留推断属性。依据不足时只保留可核实的描述，不赋精确坐标、排名或权重。
- **相对判断：**“更大／更快／主流”等表述有明确比较对象及可比依据。某产品适合某场景，只支持适配判断；市场增量及可争取份额分别举证。
- **来源冲突或不可读：**回到 Review A 的来源缺口规则，保留实际已读范围、冲突与影响，不以报告标题、摘要线索或模型声望补齐未取得的交叉表。

## 3. 覆盖不足时如何继续

先寻找同口径原始资料及可读替代来源。遇到下述 P0 获取缺口时，先向用户呈现获取决策；其余关键交叉值仍缺失时，在上表明确其影响，收窄为已有证据能支持的需求池、采用条件或适配判断，并调整依赖该数字的排序／预算结论。其他不受影响的研究可继续。

### P0 来源获取决策

按已核实的来源范围、方法、目录／样表或可读摘录，判断某来源有较大可能补齐核心证据、校正关键测算、改变研究方向或策略排序时，列为优先获取的 **P0 来源**，记录具体价值及待核实内容。只有标题线索时，先核查适用性再分级。P0 获取优先级与缺口的 `blocking / high / medium / low` 影响等级分别登记在既有来源或缺口记录中。

所有报告获取缺口在研究过程中持续登记，按 Part 汇成一份获取决策清单，P0 排前。**主 agent（Coordinator）在本 Part 或多 Part 阶段交付时，将完整清单一并呈现给用户，供其判断是否协助获取或购买**。对获取方式和替代来源做有针对性的核查，避免反复重试同一障碍；不逐个报告提问，不因获取选择尚未决定而中断流程。清单须实际交给用户审核，不能只留在本地 Notes。

清单每项至少包括：

- **具体出处：**机构、完整标题、日期／版次、URL 或文件路径；需要的章节／表格，以及实际已读和未取得的范围。
- **研究价值：**要解决什么问题、影响哪些 P／Part、Claim 或计算；拿到后可能补齐或改变什么，价值判断尚有哪些不确定性。
- **获取障碍与替代：**付费、登录／权限、机构订阅等具体障碍；已尝试的获取与替代方案，替代资料能回答到哪一层。
- **成本与建议：**可查到的官方价格、币种、授权／使用范围及获取入口；未知价格标明需询价。基于价值、适用性、时效及替代情况，建议协助获取／购买、采用替代资料继续或调整研究范围。

以完整 Part 清单或多 Part 汇总向用户呈现选择，避免把每个来源变成一次单独问答。等待期间继续研究，依赖未取得内容的判断保持待核、收窄或延后；用户选择不获取时，记录该决定及其对结论的限制，再按已有证据继续。新增采购／付费支出或联系供应商须有相应明确授权；已授权资源按原授权范围访问。

提交前应能逐项回答：结论使用了什么总体和时期、哪些假设有依据、排除的来源为何不适用、缺口会改变哪些后续判断。通过此表只表示该用途的证据取舍已说明，后续仍按 Review B 检查计算和商业推导。
