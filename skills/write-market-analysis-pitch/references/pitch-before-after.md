# 提案正反例库

用于结论像分类／资料解读、用语抽象、翻译生硬或反复修改同类表达时。先按 [写作标准](voice-and-compression.md) 检查论证，再参考对应案例改写完整句段。以下是写法及处理示意，不提供可直接沿用的行业事实。

| 问题写法 | 处理或改写示例 | 采用条件 |
|---|---|---|
| “先按用途区分家庭与商用，再看设备方案。”被当作结论 | 分类移至范围说明。标题可从已证实的发现提炼，如“住宅设备市场有望继续增长，自动化设备逐步普及”。 | 示例中的规模方向和采用变化各有证据；只有分类材料时，继续研究或收窄页面 |
| “该报告把三类产品都纳入研究，因此市场机会成立。” | 把报告覆盖范围放入方法备注；正文围绕已核实的规模、变化和采用条件展开。 | 来源覆盖哪些品类，只支持范围界定，不能自行推出机会 |
| “该地区的增量空间更广。” | 补充同口径比较对象与增量；若仅证实场景适配，则改为“该产品优先面向符合其标称覆盖范围的家庭”。 | 收窄后的适配依据成立；不保留缺少证据的相对增量判断 |
| “选型安装”“服务承接” | 根据实际服务内容写成“提供选机建议、上门设置和使用指导”，或“预约本地服务，并记录购买和完成设置”。 | 逐项核实服务及行动；不能从“安装”自动补出指导或售后 |
| “容易开始” | 已有体验依据时可说“简单易上手”；作为内容任务可写“展示首次设置过程，回答是否简单易上手”。 | 区分已证实的表现和需要展示的购买证明，保留具体场景条件 |
| “该样本不代表全国，因此不能说明……”反复出现在正文 | 将事实直接写为“受访家庭中……”或“在该渠道……”，长期方法限制集中放来源后的备注。 | 样本、地区、渠道及估计／预测属性仍随对应判断保留；无可用事实时删除该句 |
| “用户要能做在同一场地对比。” | “用户要能在同一场地对比旧机与新机。” | 调整整句语序，写清动作和对象；对比还须满足场地与型号的适用条件 |
| “技术进步，未来市场潜力巨大。” | 有机制依据时说明“安装步骤减少，使家庭更容易自行设置”；未来增速另用预测证据说明。 | 机制、实际采用和增长预测分别举证，不用修辞填补推导 |

## 改后复读

写完后分别检查：标题、大结论与Supporting能否共同说明判断和理由；完整句段是否自然、动作与对象是否清楚。涉及国家、样本、数字、排名、因果或性能的改写，再核对原意和证据强度。不要把此表做成全局词语替换清单。

有独立审读建议时，记录采纳、调整或不采纳及理由，主稿修改后再次复读。具体模型和是否启用代理由项目安排决定。

改写影响跨页结论、定义或重复用语时，按 [跨页依赖表](../../review-market-analysis/references/argument-dependencies.md) 更新相关位置；发现证据不足时回到审查 Skill，不靠润色提高结论的确定程度。
